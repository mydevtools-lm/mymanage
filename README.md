# Lior Management

מערכת ניהול אישית מקומית: משימות, יומן, ניהול כללי וכספים חודשיים.
האפיון המלא נמצא ב־[docs/SPEC.md](docs/SPEC.md), ותוכנית ההמשך ב־[docs/SPRINTS.md](docs/SPRINTS.md).

## הרצה

```bash
npm install
npm run dev
```

הדפדפן: `http://localhost:3000`.

## חיבור גוגל יומן (רשות)

קריאה בלבד — האירועים מגוגל מוצגים ביומן ובלוח הבקרה לצד האירועים המקומיים.

1. בגוגל יומן → הגדרות היומן → **שילוב יומן** → להעתיק את **כתובת סודית בפורמט iCal**
2. `cp .env.example .env.local` ולהדביק את הכתובת בשורה `GOOGLE_CALENDAR_ICS_URL=`
3. להפעיל מחדש את `npm run dev`

מצב החיבור מוצג ב־**ניהול כללי → חיבורים**. הכתובת היא סוד — היא נשארת בצד השרת
ולא נכנסת ל־git. פירוט ב־[docs/SPEC.md](docs/SPEC.md) סעיף 5.1.

## מה יש בפנים

| מסך | נתיב | תיאור |
|---|---|---|
| לוח בקרה | `/` | משימות להיום, השבוע ביומן, מאזן החודש, הוספה מהירה |
| משימות | `/tasks` | רשימה עם סינון לפי סטטוס / עדיפות / קטגוריה / חיפוש |
| יומן | `/calendar` | תצוגת חודש, פאנל יום, אירועים + משימות + אירועים מגוגל יומן |
| כספים | `/finance` | הכנסות והוצאות לפי חודש, סיכום, פילוח קטגוריות, מגמה |
| ניהול כללי | `/manage` | הערות, קטגוריות, חיבורים, גיבוי/שחזור JSON |

## Stack

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · shadcn/ui (Base UI) · Zustand · date-fns · Recharts · ical.js

## אחסון

הנתונים נשמרים ב־`localStorage` של הדפדפן. גיבוי ידני דרך **ניהול כללי → גיבוי**.
