# אפיון — Lior Management

מערכת ניהול אישית מקומית: משימות, יומן, הערות ורשימות, וניהול כספי חודשי של הכנסות והוצאות.

- **תאריך אפיון:** 22.09.2026
- **גרסה:** 1.0 (MVP)
- **סביבה:** אפליקציית Next.js שרצה מקומית על המחשב (`localhost:3000`), ללא שרת חיצוני וללא התחברות.

---

## 1. מטרה

לרכז במקום אחד את הניהול היומיומי של ליאור:

1. **משימות** — מה צריך לעשות, עד מתי, באיזו עדיפות, ובאיזה תחום.
2. **יומן** — תצוגת חודש/שבוע של אירועים ומשימות עם תאריך יעד.
3. **הערות ורשימות** — הערות חופשיות ורשימות לסימון; ובנפרד **הגדרות** — קטגוריות, חיבורים, גיבוי ושחזור.
4. **ניהול כספי** — הכנסות והוצאות לפי חודשים, החל מחודש ההתחלה (ספטמבר 2026) והלאה, עם סיכום חודשי ופילוח לפי קטגוריות.

המערכת מיועדת למשתמש יחיד, ללא הרשאות, ללא סנכרון ענן.

---

## 2. עקרונות עיצוב

- **שפה וכיווניות:** עברית, RTL מלא (`dir="rtl"`), גופן Heebo.
- **צבעוניות נעימה:** רקע שמנת בהיר, צבע ראשי ירוק‑תכלת רך (טיל), הדגשות בגוונים פסטליים. הכנסות בירוק רך, הוצאות באלמוג/ורוד רך. תמיכה במצב כהה עם אותם גוונים במונחים מרוככים.
- **ספריית UI:** shadcn/ui על Tailwind CSS v4.
- **ניווט:** חמישה מסכים ראשיים — היום, משימות, יומן, כספים, הערות ורשימות — ועוד הגדרות. במחשב סרגל צד (בצד ימין ב‑RTL), בטלפון סרגל טאבים תחתון. ראו 3.0.
- **מהירות:** כל פעולה (הוספה, עריכה, סימון) מיידית, ללא טעינה מהשרת.

## 3. מסכים

### 3.0 ניווט

חמישה מסכים ראשיים, ועוד הגדרות. במחשב — סרגל צד; בטלפון — סרגל טאבים תחתון
עם אותם חמישה (ספרינט מסכים מ2).

| מסך | נתיב | מה יש בו |
|---|---|---|
| היום | `/` | דף הבית: משימות היום, מה שנגרר, השבוע הקרוב, מאזן החודש |
| משימות | `/tasks` | כל המשימות הפעילות, וארכיון |
| יומן | `/calendar` | חודש, אירועים מקומיים ומגוגל |
| כספים | `/finance` | חודש, תנועות, פילוח, מגמה |
| הערות ורשימות | `/notes` | רשימות לסימון, הערות |
| הגדרות | `/settings` | קטגוריות, חיבורים, גיבוי — בתחתית הסרגל |

לשוניות במסכי הערות והגדרות נשמרות בכתובת (`?tab=…`), כך שאפשר לקשר ישירות
ללשונית. כתובות ישנות מופנות: `/daily` → `/`, `/manage` → `/notes`.

### 3.1 היום (`/`)

דף הבית. מחליף גם את לוח הבקרה וגם את מסך ״משימות יומיות״ הקודמים, שהציגו את
משימות היום בשני מקומות לפי כללים שונים.

| אזור | תוכן |
|---|---|
| כותרת | ברכה לפי שעה (בוקר / צהריים / ערב / לילה טוב) ותאריך |
| הוספה מהירה | משימה, אירוע, תנועה |
| בוחר יום | חצים, ״חזרה להיום״, בחירת תאריך, והחלקה בטלפון |
| התקדמות | X מתוך Y משימות בוצעו, ופס |
| כל היום | אירועים בלי שעה (מקומיים וגוגל) כרצועה |
| ציר זמן | אירועים ומשימות עם שעה, לפי השעה; קו ״עכשיו״ ביום של היום |
| במהלך היום | משימות היום בלי שעה; סימון מעביר לארכיון |
| נגררו | רק ביום של היום: משימות פתוחות שמועדן עבר, עם ״להיום״ ו״הכול להיום״ |
| בלי תאריך | רק ביום של היום: אזור מקופל, עם ״להיום״ בשורה |
| השבוע הקרוב | אירועים (מקומיים וגוגל) ומשימות לששת הימים הבאים |
| מאזן החודש | הכנסות, הוצאות ומאזן לחודש הנוכחי |

### 3.2 משימות (`/tasks`)

- **שתי לשוניות:** *פעילות* — כל המשימות שלא בארכיון, עם סינון לפי עדיפות, קטגוריה וחיפוש; *ארכיון* — משימות שסומנו כבוצעו, מקובצות לפי יום ההשלמה, עם חיפוש והחזרה.
- **מיון** ברירת מחדל: לפי תאריך יעד (הקרוב ראשון), ואז לפי עדיפות.
- **שורת משימה:** צ'קבוקס השלמה, כותרת, תגית קטגוריה, תגית עדיפות, תאריך יעד (אדום אם עבר), כפתור עריכה/מחיקה.
- **דיאלוג הוספה/עריכה:** כותרת (חובה), תיאור, תאריך יעד, עדיפות (נמוכה / רגילה / גבוהה / דחופה), קטגוריה, הערות.
- סימון משימה כבוצעה מעביר אותה לארכיון. ״החזר״ בארכיון מחזיר אותה לפעילות.

### 3.3 יומן (`/calendar`)

- **שלוש תצוגות**, והבחירה נשמרת: *חודש* (גריד 7×6; בטלפון נקודה לכל פריט),
  *שבוע* (רשת 24 שעות, אירועים חופפים זה לצד זה, לחיצה על משבצת פותחת אירוע
  באותה שעה), *רשימה* (30 ימים ברצף, ברירת המחדל בטלפון). החצים זזים לפי
  התצוגה, ו״היום״ חוזר להיום.
- בכל תא יום: אירועים (עם שעה אם יש) ומשימות עם תאריך יעד באותו יום, בצבע שונה לכל סוג.
- **לחיצה על יום** פותחת פאנל עם כל הפריטים של אותו יום — מהצד במחשב, מלמטה
  בטלפון.
- **דיאלוג אירוע:** כותרת (חובה), תאריך, שעת התחלה, שעת סיום (אופציונלי), "כל היום", מיקום, הערות, צבע.
- **אירועים מגוגל יומן** מוצגים לצד האירועים המקומיים בצ'יפ בגוון תכלת עם פס בצד, לקריאה בלבד — אי אפשר לערוך או למחוק אותם מכאן. ראה סעיף 5.1.
- **מקרא** בתחתית: אירוע / גוגל יומן / משימה / משימה שהושלמה, ולצידו שורת מצב החיבור לגוגל.

### 3.4 כספים (`/finance`)

- **בורר חודש** בראש המסך: חץ קודם/הבא, שם החודש והשנה. החודש המוקדם ביותר הוא חודש ההתחלה של המערכת (ספטמבר 2026); אין ניווט לפניו.
- **שלושה כרטיסי סיכום** לחודש הנבחר: הכנסות, הוצאות, מאזן (ירוק אם חיובי, אלמוג אם שלילי).
- **רשימת תנועות** של החודש, ממוינת לפי תאריך יורד. כל שורה: תאריך, תיאור, קטגוריה, סכום (צבוע לפי סוג), כפתורי עריכה/מחיקה. סינון לפי סוג (הכנסה / הוצאה / הכול) וקטגוריה.
- **פילוח הוצאות לפי קטגוריה** לחודש: רשימת קטגוריות עם סכום ואחוז מסך ההוצאות, מוצגת כפס יחסי.
- **מגמה חצי‑שנתית:** גרף עמודות של הכנסות מול הוצאות ל‑6 החודשים האחרונים (או מספר החודשים הקיימים אם פחות).
- **דיאלוג תנועה:** סוג (הכנסה / הוצאה), סכום (חובה, ₪), תיאור (חובה), תאריך (ברירת מחדל היום), קטגוריה, הערות.
- **תנועות קבועות:** אפשרות לסמן תנועה כ"חוזרת כל חודש". תנועה חוזרת מוצגת אוטומטית בכל חודש מתאריך ההתחלה שלה ואילך, ואפשר להפסיק אותה מחודש מסוים.

### 3.5 הערות ורשימות (`/notes`)

1. **רשימות** (ברירת מחדל) — רשימות לסימון כמו קניות לשבוע: הוספת פריט מהירה,
   סימון, פס התקדמות, ניקוי מסומנים, שינוי שם ומחיקה.
2. **הערות** — הערות חופשיות (כותרת, טקסט, תאריך עדכון), הוספה, עריכה, מחיקה
   וחיפוש.

### 3.6 הגדרות (`/settings`)

1. **קטגוריות** — קטגוריות משימות וקטגוריות כספים, לכל אחת שם וצבע. מחיקת
   קטגוריה לא מוחקת פריטים — הם נשארים בלי קטגוריה.
2. **חיבורים** — מצב החיבור לגוגל יומן (ראו 5.1).
3. **גיבוי** — ייצוא ל‑JSON, ייבוא מ‑JSON עם אישור דריסה, ומחיקת כל הנתונים עם
   אישור.

## 5. אחסון

- **שלב 1 (MVP):** כל הנתונים נשמרים ב‑`localStorage` של הדפדפן דרך Zustand עם `persist`. אין שרת, אין מסד נתונים. הנתונים שורדים ריענון וסגירת דפדפן.
- **גיבוי:** ייצוא/ייבוא JSON מהמסך "הגדרות → גיבוי", וגיבוי אוטומטי יומי של קובץ המסד ל‑`data/backups/` (14 אחרונים).
- **שלב 2 (עתידי):** מעבר ל‑SQLite מקומי דרך Route Handlers של Next.js, כדי שהנתונים יישבו בתיקיית הפרויקט ולא בדפדפן. מבנה ה‑store נבנה כך שהחלפת שכבת האחסון לא תדרוש שינוי במסכים.

### 5.1 חיבור לגוגל יומן

חיבור **קריאה בלבד** דרך כתובת ה‑iCal הפרטית של היומן. אין OAuth, אין פרויקט ב‑Google Cloud.

- הכתובת נשמרת במשתנה הסביבה `GOOGLE_CALENDAR_ICS_URL` בקובץ `.env.local` (לא נכנס ל‑git). הוראות ההשגה בקובץ `.env.example`.
- **הכתובת היא סוד.** מי שמחזיק בה רואה את כל היומן. לכן היא נקראת אך ורק בצד השרת: הדפדפן פונה ל‑`/api/calendar/google?from=…&to=…`, והשרת הוא זה שמושך מגוגל. הכתובת עצמה לעולם לא נשלחת ללקוח ולא מופיעה בהודעות שגיאה.
- ניתוח ה‑ICS ב‑`src/lib/google-calendar.ts` עם `ical.js`: אזורי זמן (VTIMEZONE) נרשמים מהפיד עצמו, אירועים חוזרים נפרשים לטווח המבוקש, מופע שנערך או הוזז בנפרד (RECURRENCE‑ID) מחליף את המופע המקורי, ואירועים עם `STATUS:CANCELLED` מסוננים.
- התוצאה נשמרת במטמון ל‑10 דקות. גוגל עצמה מרעננת את הפיד לאט, כך ששינוי ביומן יופיע במערכת תוך דקות ולא מיידית.
- אירועי גוגל אינם נשמרים ב‑store המקומי ואינם נכנסים לגיבוי — הם תמיד נמשכים מחדש.
- **מגבלה מכוונת:** אי אפשר ליצור, לערוך או למחוק אירוע בגוגל מתוך המערכת. סנכרון דו‑כיווני דורש OAuth — ראה ספרינט 3 ב‑`SPRINTS.md`.

## 9. הרצה

```bash
npm install
npm run dev
```

הדפדפן נפתח ב‑`http://localhost:3000`. בפתיחה הראשונה המערכת קובעת את חודש ההתחלה לחודש הנוכחי ומייצרת קטגוריות ברירת מחדל.
