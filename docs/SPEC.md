# אפיון — Lior Management

מערכת ניהול אישית מקומית: משימות, יומן, ניהול כללי (הערות וקטגוריות) וניהול כספי חודשי של הכנסות והוצאות.

- **תאריך אפיון:** 22.09.2026
- **גרסה:** 1.0 (MVP)
- **סביבה:** אפליקציית Next.js שרצה מקומית על המחשב (`localhost:3000`), ללא שרת חיצוני וללא התחברות.

---

## 1. מטרה

לרכז במקום אחד את הניהול היומיומי של ליאור:

1. **משימות** — מה צריך לעשות, עד מתי, באיזו עדיפות, ובאיזה תחום.
2. **יומן** — תצוגת חודש/שבוע של אירועים ומשימות עם תאריך יעד.
3. **ניהול כללי** — הערות חופשיות, קטגוריות/תחומים, גיבוי ושחזור.
4. **ניהול כספי** — הכנסות והוצאות לפי חודשים, החל מחודש ההתחלה (ספטמבר 2026) והלאה, עם סיכום חודשי ופילוח לפי קטגוריות.

המערכת מיועדת למשתמש יחיד, ללא הרשאות, ללא סנכרון ענן.

---

## 2. עקרונות עיצוב

- **שפה וכיווניות:** עברית, RTL מלא (`dir="rtl"`), גופן Heebo.
- **צבעוניות נעימה:** רקע שמנת בהיר, צבע ראשי ירוק‑תכלת רך (טיל), הדגשות בגוונים פסטליים. הכנסות בירוק רך, הוצאות באלמוג/ורוד רך. תמיכה במצב כהה עם אותם גוונים במונחים מרוככים.
- **ספריית UI:** shadcn/ui על Tailwind CSS v4.
- **ניווט:** סרגל צד קבוע (בצד ימין ב‑RTL) עם חמישה מסכים: לוח בקרה, משימות, יומן, כספים, ניהול כללי.
- **מהירות:** כל פעולה (הוספה, עריכה, סימון) מיידית, ללא טעינה מהשרת.

## 3. מסכים

### 3.1 לוח בקרה (`/`)

מסך הבית. מציג במבט אחד:

| כרטיס | תוכן |
|---|---|
| משימות להיום | משימות שתאריך היעד שלהן הוא היום או שעבר ולא הושלמו. סימון השלמה ישירות מהכרטיס. |
| השבוע ביומן | אירועים ומשימות ל‑7 הימים הקרובים. |
| מאזן החודש | סה"כ הכנסות, סה"כ הוצאות, מאזן — לחודש הנוכחי. |
| הוספה מהירה | כפתורים: משימה חדשה, אירוע חדש, תנועה כספית חדשה. |

### 3.2 משימות (`/tasks`)

- **רשימה** של כל המשימות, עם סינון לפי: סטטוס (פתוח / הושלם / הכול), עדיפות, קטגוריה, חיפוש טקסט.
- **מיון** ברירת מחדל: לפי תאריך יעד (הקרוב ראשון), ואז לפי עדיפות.
- **שורת משימה:** צ'קבוקס השלמה, כותרת, תגית קטגוריה, תגית עדיפות, תאריך יעד (אדום אם עבר), כפתור עריכה/מחיקה.
- **דיאלוג הוספה/עריכה:** כותרת (חובה), תיאור, תאריך יעד, עדיפות (נמוכה / רגילה / גבוהה / דחופה), קטגוריה, הערות.
- משימה שהושלמה נשארת ברשימה עם קו חוצה, ואפשר להחזיר אותה לפתוחה.

### 3.3 יומן (`/calendar`)

- **תצוגת חודש** בגריד 7×6, ניווט חודש קדימה/אחורה וכפתור "היום".
- בכל תא יום: אירועים (עם שעה אם יש) ומשימות עם תאריך יעד באותו יום, בצבע שונה לכל סוג.
- **לחיצה על יום** פותחת פאנל צד עם כל הפריטים של אותו יום וכפתור "אירוע חדש".
- **דיאלוג אירוע:** כותרת (חובה), תאריך, שעת התחלה, שעת סיום (אופציונלי), "כל היום", מיקום, הערות, צבע.
- **מקרא** בתחתית: אירוע / משימה / משימה שהושלמה.

### 3.4 כספים (`/finance`)

- **בורר חודש** בראש המסך: חץ קודם/הבא, שם החודש והשנה. החודש המוקדם ביותר הוא חודש ההתחלה של המערכת (ספטמבר 2026); אין ניווט לפניו.
- **שלושה כרטיסי סיכום** לחודש הנבחר: הכנסות, הוצאות, מאזן (ירוק אם חיובי, אלמוג אם שלילי).
- **רשימת תנועות** של החודש, ממוינת לפי תאריך יורד. כל שורה: תאריך, תיאור, קטגוריה, סכום (צבוע לפי סוג), כפתורי עריכה/מחיקה. סינון לפי סוג (הכנסה / הוצאה / הכול) וקטגוריה.
- **פילוח הוצאות לפי קטגוריה** לחודש: רשימת קטגוריות עם סכום ואחוז מסך ההוצאות, מוצגת כפס יחסי.
- **מגמה חצי‑שנתית:** גרף עמודות של הכנסות מול הוצאות ל‑6 החודשים האחרונים (או מספר החודשים הקיימים אם פחות).
- **דיאלוג תנועה:** סוג (הכנסה / הוצאה), סכום (חובה, ₪), תיאור (חובה), תאריך (ברירת מחדל היום), קטגוריה, הערות.
- **תנועות קבועות:** אפשרות לסמן תנועה כ"חוזרת כל חודש". תנועה חוזרת מוצגת אוטומטית בכל חודש מתאריך ההתחלה שלה ואילך, ואפשר להפסיק אותה מחודש מסוים.

### 3.5 ניהול כללי (`/manage`)

שלוש לשוניות:

1. **הערות** — רשימת הערות חופשיות (כותרת + טקסט + תאריך עדכון), הוספה/עריכה/מחיקה, חיפוש. מיועד לרעיונות, רשימות, דברים לזכור.
2. **קטגוריות** — ניהול קטגוריות משימות (למשל: עבודה, בית, לימודים) וקטגוריות כספים (למשל: משכורת, שכירות, אוכל, תחבורה). לכל קטגוריה שם וצבע. מחיקת קטגוריה לא מוחקת פריטים — הם נשארים ללא קטגוריה.
3. **גיבוי** — ייצוא כל הנתונים לקובץ JSON, ייבוא מקובץ JSON (עם אישור דריסה), ומחיקת כל הנתונים (עם אישור כפול).

## 4. מודל נתונים

```ts
type Priority = "low" | "normal" | "high" | "urgent";

interface Category {
  id: string;
  name: string;
  color: string;          // מפתח צבע מתוך פלטה קבועה
  kind: "task" | "finance";
}

interface Task {
  id: string;
  title: string;
  description?: string;
  dueDate?: string;       // ISO yyyy-MM-dd
  priority: Priority;
  categoryId?: string;
  completed: boolean;
  completedAt?: string;
  createdAt: string;
  updatedAt: string;
}

interface CalendarEvent {
  id: string;
  title: string;
  date: string;           // ISO yyyy-MM-dd
  startTime?: string;     // HH:mm
  endTime?: string;
  allDay: boolean;
  location?: string;
  notes?: string;
  color: string;
  createdAt: string;
}

interface Transaction {
  id: string;
  type: "income" | "expense";
  amount: number;         // ₪, חיובי תמיד
  description: string;
  date: string;           // ISO yyyy-MM-dd
  categoryId?: string;
  notes?: string;
  recurring?: {
    startMonth: string;   // yyyy-MM
    endMonth?: string;    // yyyy-MM, כולל
  };
  createdAt: string;
}

interface Note {
  id: string;
  title: string;
  body: string;
  createdAt: string;
  updatedAt: string;
}

interface Settings {
  startMonth: string;     // yyyy-MM — נקבע בפעם הראשונה שהמערכת נפתחת
  theme: "light" | "dark" | "system";
}
```

## 5. אחסון

- **שלב 1 (MVP):** כל הנתונים נשמרים ב‑`localStorage` של הדפדפן דרך Zustand עם `persist`. אין שרת, אין מסד נתונים. הנתונים שורדים ריענון וסגירת דפדפן.
- **גיבוי:** ייצוא/ייבוא JSON מהמסך "ניהול כללי → גיבוי". מומלץ לייצא גיבוי פעם בשבוע.
- **שלב 2 (עתידי):** מעבר ל‑SQLite מקומי דרך Route Handlers של Next.js, כדי שהנתונים יישבו בתיקיית הפרויקט ולא בדפדפן. מבנה ה‑store נבנה כך שהחלפת שכבת האחסון לא תדרוש שינוי במסכים.

## 9. הרצה

```bash
npm install
npm run dev
```

הדפדפן נפתח ב‑`http://localhost:3000`. בפתיחה הראשונה המערכת קובעת את חודש ההתחלה לחודש הנוכחי ומייצרת קטגוריות ברירת מחדל.
